# Yago Nexo

Plataforma de gestión de APIs e integración de **Sociedad de Inversiones Yago SpA**, distribuida sobre componentes de código abierto (WSO2 API Manager y WSO2 Micro Integrator, Apache 2.0) más la capa propia de Yago: Consola Nexo, motores de descubrimiento, anomalías, despliegues progresivos y continuidad, instaladores y pruebas de aceptación.

> Nombre provisorio. El desarrollo activo está en la rama `claude/brave-shannon-bafpf5`.
