Publicamos **Nexo 0.1.0**, la primera versión preliminar. Es la base sobre la que se construye la plataforma: sirve para evaluar y probar en laboratorio, y todavía no es una versión para producción.

<!-- truncate -->

## Qué incluye

- **Laboratorio local con Docker Compose.** Levanta en un equipo WSO2 API Manager 4.7.0, WSO2 Micro Integrator 4.6.0, PostgreSQL 16, Keycloak 26.8, RabbitMQ y backends de ejemplo con datos sintéticos, más dos perfiles opcionales: observabilidad y una plataforma existente simulada (APISIX y NGINX).
- **API Manager sobre PostgreSQL y Keycloak como Key Manager.** Las bases de API Manager están en PostgreSQL y las aplicaciones obtienen sus credenciales y tokens desde Keycloak.
- **Una API de ejemplo verificada de punta a punta.** El arranque del laboratorio importa la API desde su contrato OpenAPI, la publica en el gateway, crea una aplicación suscrita y comprueba que, con un token de Keycloak, la llamada a través del gateway responde 200. Luego repite la llamada sin token, que el gateway debe rechazar con 401.
- **Observabilidad básica.** Analítica y auditoría del gateway en OpenSearch mediante Fluent Bit con buffer en disco; trazas de API Manager y Micro Integrator en Jaeger mediante el OpenTelemetry Collector; métricas y reglas de alerta básicas en Prometheus y Alertmanager, y Grafana con sus orígenes de datos.
- **Biblioteca `@nexo/shared`.** Matriz rol-permiso con seis roles y acciones de cuatro ojos, eventos de auditoría con hash encadenado y su verificación, clasificación determinista de severidad y generador de datos sintéticos, con pruebas unitarias.
- **Cliente `@nexo/wso2-client`.** Cliente TypeScript de las REST API de API Manager (Publisher, Admin y Dev Portal) y de la Management API de Micro Integrator.
- **Contrato de la API de la Consola.** El contrato OpenAPI 3.1 de la futura API de la Consola, publicado como diseño en la [referencia](/docs/api-consola).

## Qué no incluye todavía

La Consola Nexo, los cuatro motores (descubrimiento de APIs, detección de anomalías, despliegues progresivos y conmutación entre sitios), los instaladores para Kubernetes (Helm, RKE2 sobre vSphere y GKE), la mesa de soporte y el portal de capacitación están en desarrollo. Esta versión tampoco incluye SBOM ni imágenes firmadas.
